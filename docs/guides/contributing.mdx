# Contributing

The repository [contribution guide](https://github.com/Annany2002/nebula-backend/blob/main/CONTRIBUTING.md) is the canonical guide for local setup, coding standards and pull requests.

Use the Go version in `go.mod` and a C compiler for the SQLite driver. Copy `.env.example`, set a development JWT secret and run `make run`. Use `./scripts/dev-email.sh` for isolated verification and recovery mail testing. Production SMTP credentials are not required for this local workflow.

Before opening a pull request, run `go test -race ./...` and `make lint`. Format Go code with `make fmt`. Include focused regression coverage for changed contracts and update the relevant API reference and [configuration guide](/guides/configuration).

Keep credentials, raw email tokens and runtime databases out of source control, issue reports and logs. Coordinate changes across the separate backend, frontend and SDK repositories. See [documentation publishing](/guides/documentation) for Mintlify validation and hosting.
