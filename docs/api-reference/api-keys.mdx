# API Keys

Generate API keys for programmatic, database-scoped access. API keys provide access to a specific database without requiring the full user JWT.

<Warning>
  API key management requires **JWT authentication**. API keys cannot be used to manage other API keys.
</Warning>

## Create API Key

Generate a new API key for a database. Repeating this request rotates the key and immediately revokes the previous key.

**Endpoint:** `POST /api/v1/account/databases/:db_name/apikey`

**Authentication:** JWT Bearer token required

<ParamField path="db_name" type="string" required>
  Name of the database to create an API key for
</ParamField>

<RequestExample>
```bash cURL
curl -X POST http://localhost:8080/api/v1/account/databases/mydb/apikey \
  -H "Authorization: Bearer <your-jwt-token>"
```
</RequestExample>

<ResponseExample>
```json 201 Created
{
  "api_key": "neb_live_abc123def456ghi789jkl012mno345pqr678stu901",
  "message": "API Key generated successfully. Store it securely - it will not be shown again."
}
```

```json 404 Not Found
{
  "error": "Database not found"
}
```
</ResponseExample>

<Warning>
  The API key is only shown **once** when created. Store it securely! If lost, repeat the POST request to rotate it. Only a SHA-256 digest and display prefix are persisted.
</Warning>

## Get API Key Info

Retrieve the display prefix and creation time. This endpoint never returns the full key.

**Endpoint:** `GET /api/v1/account/databases/:db_name/apikey`

**Authentication:** JWT Bearer token required

<RequestExample>
```bash cURL
curl http://localhost:8080/api/v1/account/databases/mydb/apikey \
  -H "Authorization: Bearer <your-jwt-token>"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "key_prefix": "neb_live_abc123de...",
  "created_at": "2026-10-02T12:00:00Z"
}
```

```json 404 Not Found (No key)
{
  "error": "API key not found"
}
```
</ResponseExample>

## Delete API Key

Revoke an API key for a database.

**Endpoint:** `DELETE /api/v1/account/databases/:db_name/apikey`

**Authentication:** JWT Bearer token required

<RequestExample>
```bash cURL
curl -X DELETE http://localhost:8080/api/v1/account/databases/mydb/apikey \
  -H "Authorization: Bearer <your-jwt-token>"
```
</RequestExample>

Returns **204 No Content** on success, or **404 Not Found** when no key exists.

---

## Using API Keys

Use the API key for database operations:

```bash
curl http://localhost:8080/api/v1/databases/mydb/tables \
  -H "Authorization: ApiKey neb_live_abc123def456ghi789jkl012mno345pqr678stu901"
```

<Note>
  API keys are **database-scoped** across records, tables, SQL, metadata, diagrams, analytics, objects and exports. Requests targeting another database return **403 Forbidden**. Database listing, creation, deletion and user/account operations require a JWT. Existing `neb_` credentials remain valid after automatic hash migration at startup.
</Note>
